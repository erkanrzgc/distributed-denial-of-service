# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not** open a public issue.

Instead, send an email to the maintainers. We will respond within 48 hours and work with you on a coordinated disclosure timeline.

## Scope

This project is an **educational and defensive security toolkit**. It is designed for:

- Security researchers testing their own infrastructure
- System administrators hardening their networks
- Penetration testers with explicit written authorization
- Educational purposes in controlled lab environments

## Out of Scope

- Issues arising from unauthorized use against third-party systems
- Deployment misconfigurations in production (use at your own risk)
- Vulnerabilities in third-party dependencies (report to upstream)

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Responsible Disclosure

We follow a 90-day disclosure timeline:

1. Report received → Acknowledged within 48h
2. Patch developed → Within 30 days
3. CVE requested → If applicable
4. Public disclosure → After patch is released

## Hall of Fame

We maintain a private list of security researchers who have responsibly disclosed vulnerabilities. With your permission, we will add you to our acknowledgments.
